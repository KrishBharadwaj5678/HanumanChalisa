# 🕉️ ハヌマーン・チャーリーサ アプリ

このアプリは、聖なる **ハヌマーン・チャーリーサ** をスマートフォンで読むことができる、シンプルで信仰的な **Flutterアプリ** です。
ユーザーが集中して読めるよう、シンプルで分かりやすい体験を提供します。

![HanumanChalisaDemo](https://github.com/KrishBharadwaj5678/HanumanChalisa/raw/main/HanumanChalisaDemo.jpeg)

## 📱 機能

| 機能                   | 説明                   |
| -------------------- | -------------------- |
| 📜 ハヌマーン・チャーリーサの全文表示 | ハヌマーン・チャーリーサをすべて表示   |
| 🎨 シンプルなUI           | 分かりやすく使いやすいインターフェース  |
| 📱 モバイル対応            | Android端末に最適化        |
| ⚡ 軽量アプリ              | 高速でスムーズな動作           |
| 🙏 信仰用途              | いつでもチャーリーサを読めるようサポート |

## 🚀 はじめに

### 1️⃣ リポジトリをクローン

```
git clone https://github.com/KrishBharadwaj5678/HanumanChalisa.git
```

### 2️⃣ プロジェクトフォルダへ移動

```
cd HanumanChalisa
```

### 3️⃣ 依存関係をインストール

```
flutter pub get
```

### 4️⃣ アプリを実行

```
flutter run
```

# 🕉️ App Hanuman Chalisa

Um aplicativo **Flutter** simples e devocional que permite aos usuários ler o sagrado **Hanuman Chalisa** em seus dispositivos móveis.
O app foi projetado para oferecer uma experiência limpa e sem distrações para os devotos.

![HanumanChalisaDemo](https://github.com/KrishBharadwaj5678/HanumanChalisa/raw/main/HanumanChalisaDemo.jpeg)

## 📱 Funcionalidades

| Funcionalidade              | Descrição                                        |
| --------------------------- | ------------------------------------------------ |
| 📜 Texto do Hanuman Chalisa | Exibe o texto completo do Hanuman Chalisa        |
| 🎨 Interface limpa          | Interface simples e fácil de usar                |
| 📱 Compatível com mobile    | Otimizado para dispositivos Android              |
| ⚡ App leve                  | Carregamento rápido e desempenho suave           |
| 🙏 Propósito devocional     | Permite ler o Hanuman Chalisa a qualquer momento |

| Tecnologia             | Finalidade                                                    |

# 🕉️ Приложение Hanuman Chalisa

Простое и духовное **Flutter-приложение**, которое позволяет пользователям читать священную **Хануман Чалису** на мобильных устройствах.
Приложение создано для обеспечения чистого и не отвлекающего опыта для верующих.

![HanumanChalisaDemo](https://github.com/KrishBharadwaj5678/HanumanChalisa/raw/main/HanumanChalisaDemo.jpeg)

## 📱 Возможности

| Функция                          | Описание                                     |
| -------------------------------- | -------------------------------------------- |
| 📜 Текст Хануман Чалисы          | Отображает полный текст Хануман Чалисы       |
| 🎨 Чистый интерфейс              | Простой и удобный пользовательский интерфейс |
| 📱 Поддержка мобильных устройств | Оптимизировано для Android-устройств         |
| ⚡ Лёгкое приложение              | Быстрая загрузка и плавная работа            |
| 🙏 Духовная цель                 | Помогает читать Хануман Чалису в любое время |
